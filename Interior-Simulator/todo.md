기준일: 2026-08-06

완료된 구현 범위와 자동 검증 증거는
[`docs/IMPLEMENTATION_STATUS.md`](docs/IMPLEMENTATION_STATUS.md), 전체 단계 설계는

## P0. 데이터 안전성과 회귀 방지

- [x] 활성 배치안 삭제 시 다음 배치안의 구조 리비전까지 복원
- [x] 새 프로젝트·로컬 프로젝트 열기·패키지 가져오기 전에 현재 프로젝트 저장
- [x] 기록 핀 삭제 시 다른 핀이 사용하지 않는 사진·썸네일 정리
- [x] 구형 LayoutDoc JSON 가져오기를 Project v2 마이그레이션 경로에 연결
- [ ] 브라우저 강제 종료·저장 실패·IndexedDB 용량 초과 복구 시나리오 수동 검증
- [ ] 대용량 사진 프로젝트 백업·복원 반복 시험

## P1. 실제 평면도 수용시험

- [ ] 사용 허가가 확보된 실제 부동산 평면도 10~20개 준비
- [ ] 지원 유형별 외벽·내벽·개구부 precision/recall 측정
- [ ] 흐림·기울기·낮은 대비·가구선 오인 실패 사례 분류
- [ ] 84㎡급 평면도 수동 추적 20분 이내 여부를 신규 사용자 3명 이상으로 측정
- [ ] 측정 결과를 `docs/DETECTION_EVALUATION.md`에 반영

## P1. 제품 품질

- [ ] Playwright E2E: 평면도 가져오기 → 축척 → 구조 편집 → 저장 → 재열기
- [ ] Playwright E2E: 배치안 생성·복제·전환·삭제와 구조 리비전 복원
- [ ] Playwright E2E: 기록 핀·사진 추가·삭제와 패키지 왕복
- [ ] 주요 2D/3D 화면 시각 회귀 기준 이미지 구축
- [ ] 키보드만으로 주요 작업이 가능한지 접근성 점검
- [ ] 모바일 화면과 터치 조작 사용성 점검

## P2. 배포 결정

- [ ] Vite 정적 웹 배포 환경과 브라우저 저장소 정책 확정
- [ ] PWA와 데스크톱 패키지 중 오프라인 요구에 맞는 형태 결정
- [ ] OCR 언어 데이터 오프라인 제공 여부 결정
- [ ] 배포 후 새 브라우저 프로필 스모크 테스트
