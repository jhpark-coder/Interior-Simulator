# Interior Simulator 남은 작업

기준일: 2026-10-23

완료된 구현 범위와 자동 검증 증거는
[`docs/IMPLEMENTATION_STATUS.md`](docs/IMPLEMENTATION_STATUS.md), 전체 단계 설계는
[`docs/FLOORPLAN_TO_3D_DEVELOPMENT_PLAN.md`](docs/FLOORPLAN_TO_3D_DEVELOPMENT_PLAN.md)를

## P0. 데이터 안전성과 회귀 방지

- [x] 활성 배치안 삭제 시 다음 배치안의 구조 리비전까지 복원
- [x] 새 프로젝트·로컬 프로젝트 열기·패키지 가져오기 전에 현재 프로젝트 저장
- [x] 기록 핀 삭제 시 다른 핀이 사용하지 않는 사진·썸네일 정리
- [x] 구형 LayoutDoc JSON 가져오기를 Project v2 마이그레이션 경로에 연결
- [ ] 브라우저 강제 종료·저장 실패·IndexedDB 용량 초과 복구 시나리오 수동 검증
- [x] 탭 닫기·숨김 직전 즉시 저장
- [ ] 대용량 사진 프로젝트 백업·복원 반복 시험

## P1. 실제 평면도 수용시험

- [ ] 사용 허가가 확보된 실제 부동산 평면도 10~20개 준비
- [ ] 지원 유형별 외벽·내벽·개구부 precision/recall 측정
- [ ] 흐림·기울기·낮은 대비·가구선 오인 실패 사례 분류
- [ ] 84㎡급 평면도 수동 추적 20분 이내 여부를 신규 사용자 3명 이상으로 측정
- [ ] 측정 결과를 `docs/DETECTION_EVALUATION.md`에 반영

## P1. 제품 품질

- [x] Playwright E2E: 평면도 가져오기 → 축척 → 구조 편집 → 저장 → 재열기
- [x] Playwright E2E: 배치안 생성·복제·전환·삭제와 구조 리비전 복원
- [x] Playwright E2E: 기록 핀·사진 추가·삭제와 패키지 왕복
- [ ] E2E를 CI(GitHub Actions 등)에서 자동 실행
- [ ] 주요 2D/3D 화면 시각 회귀 기준 이미지 구축
- [ ] 키보드만으로 주요 작업이 가능한지 접근성 점검
- [ ] 모바일 화면과 터치 조작 사용성 점검

## P1. 계획 대비 빠진 기능

`docs/FLOORPLAN_TO_3D_DEVELOPMENT_PLAN.md` 7장 요구사항과 코드를 대조해 찾은 항목이다.

- [x] 문 종류·경첩·열리는 쪽·각도 편집, 2D 열림 범위, 3D 문·창문 개폐 (v2 전환 때 빠짐)
- [x] 저장되지 않던 가구 배치 단계의 구형 문·창문 추가 제거
- [x] SIM-02 가구 복제와 잠금 토글
- [x] SIM-07 구조를 바꾼 뒤 벽 밖·벽 관통 가구를 검토 목록에 표시
- [x] SIM-04 문 열림 범위와 가구 간섭 표시
- [ ] MEM-03 기록 핀의 촬영 방향을 2D·3D에 표시 (값은 저장되지만 그리지 않음)
- [ ] IMP-03 평면도 밝기·대비 적용과 자르기 (밝기·대비는 데이터 필드만 있음)
- [ ] GEO-04 벽 길이 직접 입력
- [ ] GEO-07 벽 두께·높이 일괄 변경
- [ ] GEO-08 통로(passage) 배치 도구
- [ ] SIM-05 통행 폭 시각화
