# 평면도 인식 평가와 제품화 결정

기준일: 2026-08-06

## 현재 베타 기준

평면도 인식은 사용자 구조를 직접 덮어쓰는 자동 생성기가 아니라, **후보를 만들고 사용자가 승인하는 보조 도구**로 동작한다.

- 입력: JPG, PNG, PDF에서 렌더링한 페이지
- 처리 위치: 브라우저 로컬 Web Worker
- 기본 처리: 회색조 변환, Otsu 이진화, 고립 노이즈 제거, 기울기 추정
- 구조 후보: 가로·세로 장선 검출, 벽 두께 방향 병합, 직교 정규화
- 개구부 후보: 같은 축의 벽 선분 사이 간격에서 문·창문 후보 생성
- 텍스트 후보: 선택 시 Tesseract.js 한국어·영어 OCR
- 확정 방식: 후보별 승인 또는 거절
- 보존 원칙: 재분석은 수동 벽과 이미 승인한 벽을 삭제하거나 수정하지 않음

OCR은 최초 사용 시 언어 데이터를 내려받지만 평면도 이미지는 브라우저 밖으로 전송하지 않는다. UI에서 이 동작을 사전에 알린다.

## 반복 가능한 샘플 세트

단위 테스트의 합성 평면도 10종은 다음 변형을 조합한다.

| 변형 | 범위 |
|---|---|
| 바탕 밝기 | 244, 248, 252 |
| 벽 두께 | 3~6 px |
| 외곽 여백 | 16~25 px |
| 점 노이즈 | 3~30개 |
| 구조 | 직사각형 외곽 + 내부 벽/개구부 별도 사례 |

`detectionAlgorithm.test.ts`에서 10개 샘플 모두 주요 외곽 벽 4개 이상과 55% 이상 신뢰도 후보 4개 이상을 요구한다. 개구부 사례는 두 벽 사이 간격 후보가 생성되는지 별도로 확인한다.

이 샘플은 알고리즘 회귀를 찾기 위한 합성 fixture다. 실제 부동산 평면도에 대한
precision/recall 또는 보편적인 인식 성공률을 의미하지 않는다.

## 현재 측정 항목

각 실행은 다음 값을 UI와 상태에 남긴다.

- 처리 시간
- 이진화 임계값
- 추정 기울기
- 벽, 개구부, OCR 후보 수
- 축척 확정 여부
- 승인, 거절, 검토 대기 수
- 직접 만든 벽, 승인한 자동 벽, 미확정 후보의 3-way 비교

## 실패 유형과 수동 전환

| 실패 유형 | 표시·복구 |
|---|---|
| 축척 없음 | 10 mm/px 임시값 경고, 승인 전 축척 측정 권장 |
| 너무 밝거나 흐린 선 | 인식 임계값 직접 입력 후 재분석 |
| 기울어진 스캔 | 추정 기울기 표시 후 사용자가 보정 적용 |
| 중복·가구 선 오인 | 후보별 거절, 수동 벽 유지 |
| 문 기호 미검출 | 문·창문 수동 배치 도구 사용 |
| OCR 오인 | 텍스트 후보 거절 또는 방 이름 직접 수정 |
| 방 폐곡선 실패 | 구조 오류 마커 확인 후 벽 끝점 수동 연결 |

자동 인식이 실패해도 이미지 오버레이와 수동 추적 도구가 그대로 남기 때문에 작업을 처음부터 다시 시작하지 않는다.

## 모델 도입 판단

현재 v1.0 후보에서는 별도의 원격 세그멘테이션 모델을 기본 경로에 넣지 않는다.

1. 부동산 평면도는 개인정보가 포함될 수 있어 로컬 우선 원칙이 더 중요하다.
2. 현재 규칙 기반 결과는 설명 가능하고 후보별 신뢰도·거절 흐름과 잘 맞는다.
3. 학습 모델은 실제 실패 샘플과 정답 라벨이 충분히 모인 뒤 선택형 로컬 모델로 평가한다.

향후 모델을 넣더라도 규칙 기반 결과와 병합하고, 모델 출력 역시 사용자 승인 전에는 확정 구조로 저장하지 않는다.

## 성능 기준

- 분석 이미지는 긴 변 기준 최대 1,800 px로 축소한다.
- 픽셀 분석은 Web Worker에서 수행해 UI 스레드 중단을 줄인다.
- PDF.js, Tesseract.js는 필요한 순간에만 동적 로드한다.
- 200개 벽의 3D 메시 데이터 생성과 300개 가구 구조 검증은 각각 1초 이내를 테스트 기준으로 둔다.

## 배포 형태 검토

현재는 설치 없이 실행 가능한 Vite 웹 앱과 `.interior-project` 백업 패키지를 유지한다. PWA 또는 데스크톱 패키지는 오프라인 언어 데이터, 파일 시스템 접근, 자동 업데이트가 실제 사용자 요구로 확정될 때 별도 릴리스 트랙으로 진행한다. 핵심 데이터는 IndexedDB에 로컬 저장되며 선택한 프로젝트 패키지 외에는 외부로 전송하지 않는다.
