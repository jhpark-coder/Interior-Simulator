# 평면도 기반 3D 공간 기록·시뮬레이션 구현 상태

기준일: 2026-08-06

이 문서는
[`FLOORPLAN_TO_3D_DEVELOPMENT_PLAN.md`](./FLOORPLAN_TO_3D_DEVELOPMENT_PLAN.md)의
계획과 현재 코드·자동 테스트·수동 검증 범위를 연결한다.

현재 판정은 **기능 검증 단계의 베타**다. 핵심 코드 경로와 자동 검증은 구현됐지만,
실제 평면도 정확도, 신규 사용자 작업 시간, 모바일, 배포 패키지와 전체 E2E는
출시 수용시험으로 남아 있다.

## 구현된 전체 흐름

다음 흐름이 하나의 로컬 웹 앱에 연결되어 있다.

> JPG·PNG 또는 PDF 페이지 선택 → 축척 교정 → 수동 추적 또는 반자동 후보 검토 →
> 구조 수정 → 3D 생성 → 가구와 마감재 배치안 비교 → 사진·메모·촬영 방향 기록 →
> 1인칭 재방문 → 로컬 저장과 프로젝트 패키지 복원

프로젝트 메타데이터와 Blob은 IndexedDB에 저장된다. 기본 평면도 분석은 Web
Worker에서 실행된다. 선택적 OCR은 최초 실행 시 Tesseract 언어 데이터를
내려받지만 평면도 이미지를 원격 인식 서버로 전송하지 않는다.

## 수동 화면 검증 상태

2026-08-05에는 개발 서버에서 평면도 가져오기, 후보 검토, 작업 공간 전환, 3D,
시나리오, 사진 복원, 로컬 프로젝트와 패키지 생성을 확인했다.

2026-08-06 정합성 수정 이후에는 자동 검증을 다시 통과했지만, 새 브라우저 프로필을
사용한 전체 UI 회귀 검증은 아직 다시 수행하지 않았다. 따라서 다음 항목은 출시 전
수동 스모크 테스트로 남긴다.

1. 서로 다른 구조 리비전을 가진 배치안에서 활성 배치 삭제
2. 편집 직후 새 프로젝트·다른 프로젝트·패키지 가져오기 후 이전 프로젝트 복원
3. 단독 사진과 공유 사진이 연결된 기록 핀 삭제
4. 구형 LayoutDoc JSON 가져오기 후 벽·문·창문·가구 확인
5. `Ctrl/Cmd + S` 패키지 다운로드와 새 브라우저에서 복원

## 출시 전 외부 수용시험

- 사용 허가가 확보된 실제 부동산 평면도 10~20개로 인식 지표 측정
- 84㎡급 평면도 수동 추적 20분 이내 여부를 신규 사용자 3명 이상으로 측정
- 지원 유형별 외벽·내벽·개구부 precision/recall 목표 확정
- Playwright E2E와 주요 2D/3D 시각 회귀 구축
- 키보드 접근성, 모바일 사용성, PWA 또는 데스크톱 배포 형태 결정
- 대용량 사진 프로젝트의 장시간 저장·용량 초과·백업 복구 훈련

이 시험이 끝나기 전에는 “모든 부동산 평면도를 자동으로 정확히 변환한다”는 표현을
사용하지 않는다. 남은 작업은 [`../todo.md`](../todo.md)에서 관리한다.
